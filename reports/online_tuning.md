# Подстройка подбора по данным онлайн-теста (17.11.2026)

**Данные.** База сервера на 17.11, только чтение, выгрузка обезличена (`python -m recsys.replay export`). Показы подборок фильмов с ответом: хорошо — оценка 4–5 или «позже», плохо — «не интересно», «скрыть», оценка 1–2. Без владельца — 99 показов (50 хороших, 49 плохих) от 10 человек; и хорошие, и плохие ответы есть у 6. Все эти показы сделаны до 09.11.

**Метод.** Переигрывание журнала (`python -m recsys.replay`): для каждого показа восстанавливается состояние человека на момент показа, и настоящий рекомендатель ранжирует каталог. AUC — доля пар «хороший, плохой» одного человека, где хороший выше (среднее по людям); «общий» — по всем парам. Холодный старт — 0–2 оценки на момент показа. В скобках — 95% интервал бутстрепа по людям. Ограничители — NDCG@10 на MovieLens в сценариях `recsys/cold_start.py` с разницей по каждому человеку: small (150 человек) и 32M (1000 человек с первой оценкой от 2019 года, ALS без них).

## Найденная ошибка
В каталоге сервера 12 фильмов проката без рейтинга IMDb. Из-за них среднее рейтинга получалось NaN, и популярность становилась NaN у всех фильмов. С перезапуска бота после 15.10:
- подмешивание популярности было выключено у всех;
- новичок без оценок получал фильмы в порядке IMDb-ID: немое кино 1920–30-х, после первой оценки — малоизвестные неанглоязычные фильмы. Переигрывание с ошибкой ставит реально показанные одному новичку фильмы на места 1–5 (5 из 5, все скрыты), без ошибки их нет среди 300 кандидатов;
- /series для новичка тоже выдавал фильмы в порядке ID.

На локальном каталоге таких фильмов нет, поэтому офлайн-проверки ошибку не видели.

## Не изменено
- **Нет сигнала сверх шума на журнале:** W_ERA (0,25 / 0,75), W_LANG (0,15 / 0,5), W_NEW (0,25 / 0,5), ERA_BANDWIDTH (5 / 12), W_GENRE (0,15 / 0,5), C (0 / 0,3), CF_WEIGHT (0,3 / 0,7), N0 (2 / 10), пролистанное сразу как −0,1, «скрыть» как −1.
- **Проверить нельзя:**
  - причин отказа 4, все «не хочу такое кино»;
  - «скрыть» нажимал один человек, 5 раз;
  - данные охватывают 33 дня при полупериоде затухания 730 дней;
  - MMR переигрывание не измеряет.
- **Не трогали по условию:** порог 50 тыс. голосов, знакомство и калибровку, «бот ничего не присылает сам».

## Ограничители
- **Тесты:** 111 проходят.
- **Время ответа:** /recommend 3 / 6 / 8 мс для нового, 10 и 300 оценок — как до правок.
- **`recsys.evaluate`:** гибрид NDCG@10 0,1163 без изменений.
- **`recsys.cold_start`:** 0,0066 / 0,0050 / 0,0280 / 0,0976 → 0,0067 / 0,0074 / 0,0290 / 0,0935.
- **Память:** +1 массив на каталог (~0,2 МБ).
- **/series:** новичок получает известные сериалы, человек с оценками — сериалы по вкусу.

`MODEL_VERSION = "als32m-wnew0.35-eraref-popfix-fame-ns0"` — по нему следующую выборку можно отделить от прежних показов.
