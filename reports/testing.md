# Тестирование (этап 6)

| Проверка | Как запустить | Итог | Подробно |
|---|---|---|---|
| Юнит-тесты | `pytest` | 63 теста проходят: метрики, разбиение, профиль и его обновление, профиль на сегодня, любимые, калибровка, объяснения, MMR, запросы текстом, импорт Letterboxd, компания, опрос, миграция БД | `tests/` |
| Время ответа (ТЗ п. 4.3) | `python -m bot.benchmark` | все операции укладываются с большим запасом: команды ≤ 0,01 с (≤ 3 с по ТЗ), подборки ≤ 0,9 с (≤ 10 с), импорт 1 000 фильмов ≤ 3,8 с (≤ 60 с); настоящие нажатия — медиана 0,22 с, максимум 1,06 с | [timing.md](timing.md) |
| Холодный старт | `python -m recsys.cold_start` | без данных NDCG@10 0,048 → знакомство 0,058 → + калибровка 0,062 → импорт Letterboxd 0,107; до исправления знакомство ухудшало выдачу (0,019) | [cold_start.md](cold_start.md) |
| Офлайн-сравнение, малый набор | `python -m recsys.evaluate ml-latest-small` | лучший — гибрид ALS + контентная, NDCG@10 0,116 | [metrics_ml-latest-small.md](metrics_ml-latest-small.md) |
| Офлайн-сравнение, MovieLens 32M, выборка 20 тыс. | `python -m recsys.evaluate ml-32m --sample-users 20000 --eval-users 3000` | тот же порядок моделей: гибрид 0,129, ALS 0,117, популярность 0,076, SVD 0,032 | [metrics_ml-32m_sample20k.md](metrics_ml-32m_sample20k.md) |
| Офлайн-сравнение, MovieLens 32M, полный набор | `python -m recsys.evaluate ml-32m --eval-users 5000` | 200 947 пользователей, метрики по 5 000: гибрид 0,131, ALS 0,119, популярность 0,073, SVD 0,043 | [metrics_ml-32m.md](metrics_ml-32m.md) |
| Онлайн-тест на 10–20 людях | бот + `python -m recsys.online_stats --exclude <свои ID>` | идёт: бот спрашивает «насколько подборки подходят» после 3 и 20 оценок; режим показа (по вкусу / под настроение / поиск) записывается | `online_test.md` (появится после теста) |

## Выводы

- Гибрид ALS и контентной модели лучше всех и на малом, и на большом наборе; SVD хорошо предсказывает оценку
  (RMSE 0,82), но плохо выбирает фильмы — в бот не взят.
- Сырой рейтинг IMDb — худшая популярность: подтверждается перекос из анализа данных (накрутка у части фильмов).
- Холодный старт пришлось чинить: без подмешивания популярности 2–3 оценки давали узкий профиль хуже, чем
  просто популярные фильмы.
- На полном MovieLens 32M порядок моделей тот же, что на выборке 20 тыс.: гибрид 0,131 против 0,129, ALS 0,119
  против 0,117, популярность MovieLens 0,073 против 0,076. Заметно выросла только SVD (0,032 → 0,043, RMSE 0,82 → 0,79):
  ей больше других не хватало данных, но она всё равно в 3 раза хуже гибрида. Значит, выводы по выборке верны,
  а быстрый прогон на 20 тыс. пользователей годится для дальнейших экспериментов (6 мин против 39 мин).
- Ограничения: на полном MovieLens 32M метрики посчитаны по 5 000 случайным пользователям (обучение на всех); холодный старт — на 150 пользователях, разница в третьем знаке в пределах шума;
  цикл отложенных вопросов «посмотрел?» проверен вживую, без юнит-теста.
